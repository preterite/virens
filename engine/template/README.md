# VIRENS User Instance Template

**License:** This template inherits the [AGPL-3.0](../../LICENSE) license from the VIRENS Framework.

This directory provides the scaffold for a new user instance.

## Structure

- `config/` - User configuration files
- `dotfiles/` - Shell and application dotfiles
- `obsidian-vault/` - Empty Obsidian vault structure
- `observatory/` - Observatory data directory
- `machines/` - Machine-specific configurations

## Usage

During installation, this template is copied to:
`~/Local/virens/user1/` (sibling to the `virens/` framework directory)

You then customize the files for your personal use.
